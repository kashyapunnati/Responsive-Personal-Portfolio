# 💻 Responsive Personal Portfolio Website

A responsive personal portfolio website created to showcase my skills, web development work, education, and learning journey.

## ✨ Features

- 🏠 Home section
- 👤 About Me section
- 🛠️ Skills section
- 📂 Projects section
- 🎓 Education & Experience section
- 📩 Contact form
- 📱 Responsive navigation
- ☰ Mobile hamburger menu
- ✅ Contact form validation
- 📧 Email format validation
- 🎨 Responsive and modern design
- 🔄 Smooth navigation between sections

### Technologies
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Responsive Web Design

### Development Tools
- Visual Studio Code (VS Code)
- Git
- GitHub
- GitHub Pages

## 🔧 Development Workflow

The website was developed using **Visual Studio Code**.

**Git** was used for version control, and **GitHub** can be used to store and manage the source code repository.

**GitHub Pages** can be used to deploy the website online.
